# 键盘下方状态（KeyboardStatus）

在 iOS 系统键盘**底栏**加一排**可用功能按钮**，外加一条（可选）只读状态条。

- 越狱环境：iOS 16 rootless（Dopamine / Relaxin / RootHide 隐根）
- 入口：系统「设置」→「键盘下方状态」

## 功能按钮（默认全开，可单独关）
全选 / 剪切 / 粘贴 / 光标左右移动 / 剪贴板历史 / 快捷短语（可增删、跨 App 共享）/ 收起键盘。

## 智能隐藏（1.3.3 新增，默认开）
输入验证码、密码、纯数字/电话键盘，以及游戏自绘键盘（隐藏输入框）的场景下，工具栏自动不显示；正常打字（QWERTY 文本框）时照常出现。设置里可关。

## 1.3.7 更新
- **快捷短语支持批量导入**：短语编辑页（键盘点「语」按钮进入）右上角新增「批量」按钮 → 弹出多行文本框，**自动填入当前剪贴板内容**；确认后按换行分隔一次性导入，自动忽略空行、跳过重复项。另有「覆盖原有短语」开关，关（默认）为追加、开为清空后导入。复制一串分行文本 → 点批量 → 直接导入即可。

## 1.3.6 更新（两个 bug 真正修好）
- **修复「全删」清不掉候选字（打中真因）**：1.3.5 用 `replaceRange(markedTextRange)` 在 WKWebView/部分输入框上会抛异常被吞，且没动键盘自己的组合态。现改用 UITextInput 合规的 `setMarkedText:@"" + unmarkText`，并**直接清键盘实例 UIKeyboardImpl 的组合态**（候选条是它持有渲染的），清正文前后各清一遍，候选条随正文一起消失。
- **修复「快捷短语」删了又出现（打中真因）**：根因是**读侧 `KSCopyPref` 文件缺键不回退 CFPreferences**——短语只落进 CFPreferences 时（jbroot 文件直写失败），读侧无视它 → 回退默认。现 `KSCopyPref` 在文件缺键时回退 CFPreferences，写读两路一致，删空即永久生效。

- 1.3.5 对「全删/短语」的修法未打中根因，已在 1.3.6 重做。

## 状态条（可选，纯显示）
时间 / 电量 / 剪贴板预览 / 网络(WiFi/蜂窝)，约 1 秒刷新一次。

## 安全设计（防 dock 卡死 / 白苹果）
- **只注入普通 App**，明确排除 `SpringBoard` 与 `Preferences`（设置）。
- 全部逻辑包在 `@try/@catch`；任一动作异常都不影响宿主 App。
- 总开关 + 每个功能独立开关，出问题时关总开关即恢复原生键盘。
- 不调用 CoreTelephony 等易崩框架；网络检测用标准 BSD `getifaddrs`。

## 构建 / 发布
- 推送到 GitHub → Actions 自动出 `packages/*.deb`
- 走既有越狱源发布流程（同 超级截图 / 隐私总开关）

## 指定注入的 App
编辑 `layout/Library/MobileSubstrate/DynamicLibraries/KeyboardStatus.plist` 的 Bundles 数组，加入目标 App 的 bundle id 即可。
